# codex-auto-resume

> 🤖 **OpenAI Codex Desktop App** 的 24/7 全天候静默后台守护工具。自动监测并响应 5 小时滑动额度恢复与社区熟知的 Tibo 突发空投重置，毫秒级无感唤醒“恢复目标”。100% 纯后台静默运行，绝不强弹窗口，绝不污染上下文。

---

## 痛点背景

在使用 **OpenAI Codex Desktop App** 运行多阶段自主任务（Goals / 目标）时，会因为账号每 5 小时的滑动使用限制而自动进入 `usage_limited` 暂停状态。

除固定的 5 小时窗口外，OpenAI 负责人（如推特/X 社区熟知的 **Tibo**）经常会突发向用户群体批量发放额度重置补偿（“放水”）。开发者通常面临以下困扰：
1. **人工定时守候**：需要频繁切回界面查看额度是否刷新，手动点击**“恢复目标”**按钮。
2. **命令发消息打扰上下文 (`codex queue --message`)**：会在聊天记录里产生无意义的用户蓝色气泡，不仅污染对话历史，还会浪费上下文 Token。
3. **传统鼠标点击宏的缺陷**：暴力模拟鼠标点击不仅会抢占鼠标和窗口焦点，若窗口被最小化或出现位移，误点击到系统桌面壁纸还会触发 macOS 的“点击壁纸显示桌面”，导致前端所有正在工作的窗口瞬间缩进边缘。

## 解决方案

**`codex-auto-resume`** 专为优雅解决长时任务接续痛点而设计：

- **100% 静默无感恢复**：通过 macOS 原生辅助功能树（Accessibility API / `System Events`）在底层直接精准触发“恢复目标”按钮。**鼠标光标 0 位移、窗口 0 强弹/置顶、0 焦点抢占、绝不误触壁纸**。
- **智能感知 Tibo 突发重置**：除精准对齐服务端给出的 5 小时时间戳外，每隔 3 分钟通过纯后台无头命令行（0 GUI）向 OpenAI 接口静默发起探测。一旦捕获到提前放水，秒级触发恢复。
- **绝不污染上下文**：走官方原生的 `thread/goal/set` 目标生命周期通道，会话历史里 0 垃圾气泡。
- **零外部依赖包**：完全基于 Python 标准库与 macOS 系统原生工具构建，**无需 `pip install` 任何第三方包**，开箱即用。

---

## 核心特性

- 🕒 **5 小时滑动窗口追踪**：自动读取本地会话元数据，精准计算额度刷新的精确时刻。
- ⚡ **Tibo 提前放水探测**：每隔数分钟无头静默嗅探后端配额，不错过任何一次提前重置的福利。
- 🎯 **自适应会话识别**：自动检索本地最新运行的目标会话，亦可随时通过 `--thread-id` 手动指定。
- 🔕 **真正的后台守护服务**：可常驻后台（支持 `nohup`），在你办公、游戏或离席休眠时安静守护。

## 前提条件

- **macOS 12+**（已在 macOS 14 Sonoma、15 Sequoia 及 26+ 上实测验证）
- **Python 3.8+**（直接使用 macOS 自带 Python 即可）
- **辅助功能权限**：确保终端应用（Terminal / iTerm2 等）拥有辅助功能控制权限（系统设置 → 隐私与安全性 → 辅助功能）

## 快速上手

```bash
# 1. 克隆仓库
git clone https://github.com/Tiggy-Chan/codex-auto-resume.git
cd codex-auto-resume

# 2. 检查当前会话目标与额度重置状态（输出 JSON）
./codex_auto_resume.py --status

# 3. 启动守护进程（自动检测最新的目标会话）
./codex_auto_resume.py

# 4. 或作为后台常驻守护进程运行
nohup ./codex_auto_resume.py --log ~/.codex/codex_auto_resume.log > /dev/null 2>&1 &
```

---

## 命令行参数说明

| 参数 | 说明 | 默认值 |
| :--- | :--- | :--- |
| `-t, --thread-id` | 指定监控的 Codex 会话 UUID | *自动检测最新活跃会话* |
| `-i, --interval` | 本地状态扫描周期（秒） | `45` |
| `-p, --probe-interval` | 无头向 OpenAI 探测额度的周期（秒） | `180`（3 分钟） |
| `-l, --log` | 日志保存路径 | *仅输出至控制台* |
| `--status` | 输出当前目标状态、重置时间戳及配额诊断 JSON，然后退出 | - |
| `--click-only` | 立即执行一次原生的恢复目标点击，然后退出 | - |
